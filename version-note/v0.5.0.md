Usando el contexto global de `retrykafka`, implementar `v0.5.0`.

# Objetivo

Agregar soporte opcional para:

```text
Tracing
Metrics
Trace Context Propagation
```

# Default Providers

Utilizar:

```go
otel.GetTracerProvider()
otel.GetMeterProvider()
```

Permitir providers custom.

# Publisher

Crear spans:

```text
messaging.publish
```

Inyectar trace context en Kafka Headers.

# Consumer

Extraer contexto.

Crear:

```text
messaging.consume
messaging.process
messaging.retry.publish
messaging.dlq.publish
```

Mantener relación correcta entre spans.

# Metrics

Implementar:

```text
messages_processed_total
messages_failed_total
retry_attempts_total
messages_sent_dlq_total
handler_duration
```

Evitar:

```text
message_id
offset
user_id
```

como labels/attributes de métricas por alta cardinalidad.
