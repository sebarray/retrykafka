# Objetivo

Construir la base de la librería.

Esta versión debe incluir:

```text
Publisher
Consumer
Message Envelope
Message Identity
Kafka abstraction/client integration
Concurrency-safe design
Basic offset handling
```

No implementar todavía Retry Topics, DLQ, Idempotency o OpenTelemetry.

# Publisher

Implementar un Publisher thread-safe.

API conceptual:

```go
publisher := retrykafka.NewPublisher(
    retrykafka.WithBrokers("localhost:9092"),
)

err := publisher.Publish(
    ctx,
    "payments",
    payload,
)
```

El Publisher debe:

```text
Generate Message ID
Serialize payload
Attach metadata
Publish
```

Metadata:

```text
x-message-id
x-produced-at
```

El Message ID debe generarse por operación.

No almacenar IDs en estado mutable compartido.

# Consumer

Permitir registrar handlers.

Ejemplo:

```go
consumer.Handle(
    "payments",
    func(ctx context.Context, msg Message) error {
        return processMessage(ctx, msg)
    },
)
```
