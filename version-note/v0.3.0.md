Usando el contexto global de `retrykafka`, implementar `v0.3.0`.

# Objetivo

Mejorar:

```text
Configuration
Defaults
Functional Options
Per-topic configuration
Topic naming
Developer Experience
```

# Functional Options

Permitir:

```go
retrykafka.New(
    retrykafka.WithBrokers("localhost:9092"),
    retrykafka.WithMaxAttempts(5),
)
```

# Defaults

```text
Retries: 3

Backoff:
5s
30s
5m

DLQ:
Enabled

Retry naming:
{topic}.retry.{attempt}

Logging:
slog.Default()

Auto Create Topics:
false

Idempotency:
disabled
```

# Per Topic Overrides

Permitir:

```go
consumer.Handle(
    "payments",
    handler,
    retrykafka.WithMaxAttempts(5),
)
```

La configuración por topic debe sobrescribir correctamente los defaults globales.

# Topic Naming

Permitir:

```go
retrykafka.WithTopicNamer(...)
```

Diseñar una interfaz clara.

# Auto Create Topics

Agregar:

```go
retrykafka.WithAutoCreateTopics(true)
```

Default:

```text
false
```

Documentar que production infrastructure puede administrar topics externamente.
