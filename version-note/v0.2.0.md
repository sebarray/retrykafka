
# Backoff

Default:

```text
5s
30s
5m
```

Implementar una estrategia correcta.

Analizar cuidadosamente cómo manejar delayed retries sin bloquear incorrectamente consumers o particiones.

Documentar el mecanismo elegido y sus limitaciones.

# Retry Flow

```text
Handler Error
      │
      ▼
Publish Retry Message
      │
      ▼
Commit Original Offset
```

Documentar explícitamente que esto puede producir duplicados si ocurre un crash entre ambas operaciones.

La semántica es:

```text
At-least-once
```

# DLQ

Cuando se agotan los retries:

```text
{topic}.dlq
```

Preservar:

```text

Message ID

Retry Metadata

```
